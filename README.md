# darwon-demo (prezentácia)

Statická prezentačná stránka k živej ukážke Darwon (fiktívne štúdio Lumen Wellness Studio). Nasadenie na Vercel bez buildu okrem
nahradenia tokenu `__APP_URL__` adresou demo aplikácie (premenná prostredia `APP_URL`, napr. `https://darwon-demo-app.vercel.app`).
Kód aplikácie: vetva `darwon-demo` v repozitári webdavid-rezervacie.
